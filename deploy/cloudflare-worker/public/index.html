Mac / Windows 第一次打开弹出系统安全提醒怎么办？ +
这是因为 OpenUU 是个人免费开源作品（全部源码在 GitHub 公开可查），暂时没有每年付费购买苹果或微软的商业企业签名证书，属于系统的正常首次提醒，软件本身完全安全。
Windows 电脑：双击运行安装版 OpenUU-*-Setup.exe（或解压便携版双击 OpenUU.exe），若弹出蓝色 SmartScreen 窗口，点击「更多信息」→「仍要运行」即可直接打开（无需安装额外依赖；若需远控以管理员权限运行的软件窗口，可在设置内一键以管理员身份重启）。
Mac 电脑（方式一）：在弹窗点「完成」，然后打开 Mac 的「系统设置 → 隐私与安全性」，滑到最底部点一下「仍要打开」即可。
Mac 电脑（方式二，最快）：把 OpenUU 拖进「应用程序」文件夹后，打开「终端」粘贴下面这行命令回车，就能直接打开：
xattr -cr /Applications/OpenUU.app
